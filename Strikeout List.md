# Strikeout List — Ideas Already Considered

Every crossed-out title below has already been proposed, screened, or tested. The brief reminder is only to prevent the same idea returning under a new name. **Do not promote or regenerate any of these without a materially different scientific claim and new evidence.** A strikeout does not mean the physics is impossible. The old detailed brainstorming is removed from the current portfolio; Git history retains previously committed versions. Completed Phase 0 result files remain as evidence.

## Rule for future idea searches

Search this list before proposing another idea. A new title, algorithm, encoding, device, or application does **not** reset the strikeout. A revival needs a precise new observation, theorem, or experimentally testable decision that survives the closest published work and prior negative tests.
