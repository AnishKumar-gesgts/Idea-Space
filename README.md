## Current focus

The novelty-first Round 2 screen now guides project selection. Idea 1's Phase 0 found a real model-level calibration ambiguity but did not establish a physically calibrated or sufficiently novel standalone project. The revised shortlist asks a sharper question of every candidate before larger implementation: what could it show that the closest paper cannot? The earlier idea sets, decoder evaluations, and photonic-QEC documents remain available as historical research and reproducible negative results.

Start with the [novelty-first shortlist](./Novelty-First%20Quantum%20Photonics%20Idea%20Search%20%E2%80%94%20Round%202.md). Use the [earlier ranked evaluation](./Quantum%20Photonics%20and%20Information%20Science%20%E2%80%94%20STORM%20Idea%20Evaluation.md), [QEC handoff](./Photonic%20QEC%20Research%20Ideation%20%E2%80%94%20Model%20Handoff%20Protocol%20%28Unedited%29.md), and [decoder evaluations](./Photonic%20Decoder%20Evaluations.md) for prior ideas and their evidence trail.

## Mathematical notation

The handoff uses standard Markdown math delimiters:

$$
P_L^{\mathrm{reduced}} \approx P_L^{\mathrm{microscopic}}
$$

GitHub's repository renderer supports these expressions directly. The hosted site also loads MathJax for the same notation.
