## Current focus

The newest idea set moves the research search toward quantum photonics and quantum information science. Its first Phase 0 found a real model-level calibration ambiguity, but did not establish a physically calibrated or sufficiently novel standalone project; its no-go decision and code are linked above. The decoder and photonic-QEC documents remain available as historical research and reproducible negative results.

Start with the [new ranked idea evaluation](./Quantum%20Photonics%20and%20Information%20Science%20%E2%80%94%20STORM%20Idea%20Evaluation.md). Use the [QEC handoff](./Photonic%20QEC%20Research%20Ideation%20%E2%80%94%20Model%20Handoff%20Protocol%20%28Unedited%29.md) and [decoder evaluations](./Photonic%20Decoder%20Evaluations.md) for the earlier ideas and their evidence trail.

## Mathematical notation

The handoff uses standard Markdown math delimiters:

$$
P_L^{\mathrm{reduced}} \approx P_L^{\mathrm{microscopic}}
$$

GitHub's repository renderer supports these expressions directly. The hosted site also loads MathJax for the same notation.
